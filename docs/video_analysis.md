# 새 영상 비교 분석

입력: `videos/original/desk_objects.mp4`, 1080×1920, 30fps, 403프레임, 약 13.43초.
추적은 원본 프레임 전부에 수행한 뒤 2배속을 적용했다. 약 6.72초, 60fps, 403프레임으로 **전체 구간을 유지**하며 무음이다.
비교 영상의 source 시간은 원본 시각이다. 실제 2배속 재생 시각은 source의 절반이다.

| 원본 시각 | 로컬 196장·75회 | Colab 414장·50회 |
|---|---|---|
| 0.00초 | 세 클래스 감지. 컵 #1, 마우스 #3, 리모컨 #2 | 동일한 초기 주요 ID로 세 클래스 감지 |
| 3.50초 | 실제 마우스를 cup #3으로 오분류 | 실제 마우스를 mouse #3으로 감지 |
| 6.30초 | 실제 컵 ID #1 | 실제 컵 ID가 #6으로 변경 |
| 7.00초 | 주요 세 물체 감지 | 컵 박스 중복과 범위 확장 관찰 |
| 7.80초 | 들어 올린 마우스 감지. 컵은 크게 가려지고 출력 없음 | 마우스 박스가 손까지 크게 확장. 컵 출력 없음 |
| 8.50초 | 컵 #1, 마우스 #3 | 실제 컵 #3, 실제 마우스 #13으로 연결 변경 |
| 11.50~13.30초 표본 | 리모컨 #2, 마우스 #3 | 리모컨 #13, 마우스 #25로 변경 |

최종 모델로 **로컬 196장·75회**를 선정하였다. 시작·종료 주요 ID가 같고 확인한 주요 장면에서 연결이 상대적으로 안정적이었다.
다만 로컬에도 오분류와 일시적 감지 불안정이 있어 완벽한 ID 유지나 모든 장면의 우수성을 의미하지 않는다.
프레임별 정답 박스·ID를 만들지 않아 영상 mAP, IDF1, 정식 ID 전환 횟수는 산출하지 않았다.

두 모델의 추론은 모두 CPU/FP32, imgsz640, conf0.25, iou0.70, ByteTrack, stride1로 실행했다.
모델 이름의 LOCAL/COLAB은 **학습 환경**이며 영상 비교가 GPU 간 속도 실험이라는 뜻이 아니다.
