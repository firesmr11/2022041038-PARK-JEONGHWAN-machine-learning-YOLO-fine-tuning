# 준비 파일의 검증 범위

2026년 11월 23일에 다음을 확인하였다.

- 데이터 검사 단위 테스트 4개 통과: Roboflow 상대 경로, 객체/이미지 수 구분, 라벨 누락, 비정상 좌표, 라벨 변경 해시 검증을 포함한다.
- 실제 제공 모델을 이용하여 별도의 1프레임 임시 데이터에서 evaluate.py를 실행하고 test 분할 평가, 콜백을 통한 출력 경로 수집, 결과 JSON 저장이 완료됨을 확인하였다.
  이 임시 데이터는 API 동작 확인용이며 보고서의 테스트 지표에 포함하지 않았다.
- 제공된 모델 7개의 크기와 SHA256 체크섬이 기록과 일치하였다.
- 테스트 비교표에 12개 환경·데이터·에포크 조합이 중복 없이 포함되어 있고 지표 범위가 올바름을 확인하였다.
- 원본 및 제출 영상 5개를 처음부터 끝까지 디코딩하였다. 모두 403프레임이며 2배속 3개는 60fps·약 6.72초, 원속도 2개는 30fps·약 13.43초이다.
- 비교 그래프와 손실·검증 성능 그래프를 생성하고 시각적으로 확인하였다.
- 공개 대상 텍스트에 API 키 값과 개인 컴퓨터의 절대 경로가 섞이지 않았는지 검사하였다.

전체 원본 학습 데이터와 이 컴퓨터의 RTX 4060이 없어 12개 학습을 다시 수행하지는 않았다.
학습 코드는 CLI와 구문을 확인하였으며, 이번 준비 작업에서 GPU 학습 완료까지 새로 검증한 것으로 표기하지 않는다.
실행 확인 환경은 Python 3.12.10, PyTorch 2.14.1+cpu, Ultralytics 8.4.216이었다.
