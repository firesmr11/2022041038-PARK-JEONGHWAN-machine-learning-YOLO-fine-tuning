# 교수님 과제 요구사항과 제출 상태

과제 근거: 제공된 「ML-10 컴퓨터비전-4」 49~51쪽. 강의자료 원본은 저장소에 재배포하지 않았다.

| 요구사항 | 준비한 내용 | 현재 상태 |
|---|---|---|
| 3개 부류 및 100개 이상의 이미지 수집 | cup·mouse·remote, v1 254장 / v2 472장 | 수행 결과와 분할·객체 수 기록. 전체 데이터는 별도 보관 |
| 세 부류에 대한 학습 | YOLOv8n, 196/414장 × 25/50/75회 × Colab/로컬 | 12개 결과 정리, 제공된 모델 7개 포함 |
| 학습된 부류의 감지와 추적 동영상 | ByteTrack ID와 궤적 표시 | 전체 원본 13.43초 및 전체 2배속 6.72초 영상 포함 |
| 5초 분량의 결과 동영상 | 현재 주 제출용은 사용자 요청에 따른 약 6.72초 전체 2배속 | 안내의 정확한 5초와 다름. 길이 조건을 충족했다고 단정하지 않음 |
| 개인 공개 GitHub에 모델과 동영상 저장 | models/ 및 videos/를 일반 Git 추적 대상으로 준비 | 로컬 준비 완료, 공개 저장소 생성·업로드는 미수행 |
| 보고서 학습 과정 및 성능 | docs/report_1_3_to_9.txt, results/ | 1.3~9장 작성. 기존 1.1·1.2 및 표지와 합쳐 제출 |
| 보고서 GitHub 링크 | README 및 보고서에 입력 위치 표시 | 공개 후 실제 주소 입력 필요 |
| 과제 과정에서 경험한 내용 | 보고서 7장 | 작성 완료 |

커밋 전 준비를 마친 뒤 사용자의 후속 요청에 따라 로컬 커밋을 진행하였다. 원격 저장소 생성, push, 공개 설정은 하지 않았다.
최종 HWP/PDF 보고서도 사용자가 기존 문서에 본문을 옮긴 뒤 별도로 저장해야 한다.
